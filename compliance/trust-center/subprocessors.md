## Data Processing

### Data Types

We share the following types of data with subprocessors:

- **User Data**: Names, email addresses, phone numbers
- **Document Data**: Document metadata, signature data
- **System Data**: Logs, metrics, performance data
- **Error Data**: Error logs, stack traces

### Data Protection Measures

All subprocessors are required to:

- Implement appropriate technical and organizational measures
- Comply with applicable data protection laws
- Maintain data confidentiality, integrity, and availability
- Report data breaches within 24 hours
- Delete or return data upon termination

## Changes to Subprocessors

We may add or replace subprocessors from time to time. Significant changes will be notified via:

- Email notification to customers
- Update to this document
- Posting on our trust center
